# Event contract

All timestamps use ISO 8601 with a timezone. Identifiers are strings generated by
the producer. Coordinates use WGS84 decimal degrees.

## Telemetry

```json
{
  "type": "device.telemetry",
  "deviceId": "tractor-001",
  "occurredAt": "2026-08-01T14:12:30+09:00",
  "imu": {
    "accelX": 0.02,
    "accelY": 0.91,
    "accelZ": 0.12,
    "gyroX": 1.2,
    "gyroY": 0.5,
    "gyroZ": 0.2,
    "roll": 76.0,
    "pitch": 8.0
  },
  "location": {
    "latitude": 36.3012,
    "longitude": 127.5874,
    "speedKph": 0.0,
    "valid": true
  },
  "impactG": 2.8,
  "inactiveSeconds": 5.0,
  "batteryPercent": 78,
  "solarCharging": true
}
```

## Risk result

```json
{
  "classification": "rollover",
  "riskScore": 0.94,
  "evidence": ["dangerous_tilt", "impact", "inactivity"],
  "modelVersion": "rules-v1"
}
```

`classification` is one of `normal`, `slope`, `vibration`, or `rollover`.

The firmware-facing JSON Schema and a copyable example are maintained in
[`device/protocol`](../device/protocol/README.md). Changes to the Pydantic model and
the committed device schema must be made together; contract tests reject drift in
required fields.
